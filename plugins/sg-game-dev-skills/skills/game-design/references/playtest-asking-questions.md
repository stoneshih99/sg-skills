# 問卷與訪談怎麼問

問錯問題會得到禮貌的謊言。人會想當好客人、想顯得聰明、想合理化自己的行為——問題設計就是在繞過這三件事。

## 鐵則

- **不問「好不好玩」**：99% 的人會說「蠻好玩的」。這題唯一的功能是讓團隊自我感覺良好。
- **問具體經驗，不問一般意見**：「剛剛」發生的事 > 「你覺得」的評論。
- **問過去行為，不問未來意願**：「你會買嗎」的回答與實際購買幾乎無關；「你剛剛玩到哪裡想停」才有訊號。
- **先開放後封閉**：先讓玩家自己說（開放題），再確認細節（封閉題）。順序反了，你的選項會框住他的記憶。

## 好用的訪談問題

**挖體驗峰谷：**
- 「剛剛哪個**瞬間**最有感覺？帶我回到那一段。」（強迫具體）
- 「有沒有哪個瞬間你覺得煩、想跳過？」
- 「有沒有哪裡你覺得『這遊戲在耍我』？」（挫折但不怪玩家的問法）

**挖理解與心智模型：**
- 「用一句話跟朋友介紹這遊戲，你會怎麼說？」（測定位與理解）
- 「你覺得 <機制 X> 是做什麼用的？」（對照設計意圖）
- 「剛剛在 <卡點>，你當時在想什麼？」（回放行為，挖決策過程）

**挖動機：**
- 「如果現在能繼續玩，你想做什麼？」（比「還想玩嗎」誠實）
- 「這遊戲讓你想起哪些玩過的遊戲？哪裡像、哪裡不像？」（定位與期待）

## 追問技巧

- **「為什麼」換句話說**：連環「為什麼」有審問感，改用「多說一點？」「那時候你預期會發生什麼？」。
- **沉默是工具**：問完閉嘴數三秒，人會自己補充最真實的部分。
- **對模糊詞追殺**：玩家說「有點卡」「怪怪的」——「卡是指哪種卡？操作上的還是節奏上的？」模糊詞底下才是真問題。
- **不確認自己的假設**：不問「你是不是因為看不到提示才卡住？」（誘導），問「你當時在找什麼？」。

## 問卷（如果要用）

問卷適合多輪比較與量化趨勢，不適合挖原因：

- 用行為回憶題與具體評分：「你在第幾關停下來的？」「重玩意願 1-7 分」。
- 同一份問卷跨輪次不改題目，才能比較改動前後。
- 樣本小（< 10 人）時，問卷數字沒有統計意義，只當訪談的引子。

## 收斂與解讀

- **玩家是問題的專家，不是解法的專家**：「你們應該加個地圖」→ 記下的是「他迷路了」，不是「要加地圖」。解法自己想。
- **行為與說法矛盾時，信行為**：說「難度剛好」但重試了 15 次面露猙獰——資料是後者。
- **分開「資料」與「詮釋」**：筆記欄位分兩欄，先抄實話實錄，詮釋另外寫，避免記錄當下就腦補。

## 常見陷阱

- **誘導題**：「你不覺得教學有點長嗎？」——你已經替他答了。
- **一題多問**：「操作和 UI 你覺得如何？」他只會答其中一個。
- **當場修 bug / 辯護 / 允諾**：「這我們會改」會讓玩家開始講你想聽的。
- **把訪談當統計**：3 個人說想要 X 不代表該做 X；訪談找的是「為什麼」，數量結論交給更大樣本。

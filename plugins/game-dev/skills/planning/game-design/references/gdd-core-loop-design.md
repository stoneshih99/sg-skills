# 核心循環（Core Loop）設計要點

核心循環是玩家反覆進行的最小行為單位，是遊戲樂趣的引擎。企畫階段要能把它講清楚。

## 一個完整循環的四段

1. **行動（Action）**：玩家主動做的事（射擊、放置、選擇）。
2. **回饋（Feedback）**：系統立即回應（命中、數字跳動、音效光效）。
3. **進展（Progress）**：累積成長（資源、等級、解鎖、劇情推進）。
4. **再行動（Re-engage）**：進展如何驅動下一次行動，形成閉環。

## 檢查清單

- [ ] 這個循環一句話講得完嗎？
- [ ] 單次循環的時間長度是多少？（秒 / 分 / 局）
- [ ] 回饋是否即時且清楚，玩家知道自己做得好不好？
- [ ] 進展是否讓下一次循環「不一樣」（新選擇 / 新難度 / 新資源）？
- [ ] 循環是否會膩？靠什麼變化維持新鮮（隨機、難度曲線、新機制解鎖）？

## 常見陷阱

- **有行動沒回饋**：玩家不知道操作有沒有效果，體感空洞。
- **有回饋沒進展**：短期爽但無累積動機，留存差。
- **循環太長**：單次循環太久，挫折累積、學習成本高。

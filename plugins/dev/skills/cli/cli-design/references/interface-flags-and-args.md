# CLI 介面：args、flags、子命令、設定

介面設計錯了之後改不動——使用者的 script 已經依賴它（介面即契約，改= breaking change）。這篇是第一次就把介面設計對的決策。

## 位置參數 vs 旗標

- **位置參數（args）**：留給「這個命令天然的主詞」——通常是**操作對象**（檔案、路徑、名稱）：`cp SRC DST`、`grep PATTERN FILE`。超過 2 個位置參數就難記（誰先誰後？）——第 3 個起改旗標。
- **旗標（flags/options）**：一切修飾行為的東西。旗標自帶名字、順序無關、可省略——比「第四個位置參數」友善得多。
- **判準**：必填且是主要對象→位置參數；可選、修飾、模式切換→旗標。**別用位置順序編碼語意**（`mytool a b c d` 誰記得住）。

## 旗標慣例（別發明新規則）

使用者對旗標有肌肉記憶，遵守慣例=免學習成本：

- **短旗標 `-v` + 長旗標 `--verbose` 成對**：短的給互動輸入省字，長的給 script 自我說明（**script 裡寫長旗標**——半年後讀 script 的人不用查 `-f` 是啥）。
- **標準旗標別挪用**：`-h/--help`（說明）、`--version`（版本）、`-v`（verbose 或 version——擇一並一致）、`-q/--quiet`、`-f/--force`、`-o`（輸出）、`-n/--dry-run`。把 `-h` 拿去當別的用途是對使用者宣戰。
- **`--` 分隔旗標與參數**：`--` 之後全是位置參數——讓檔名恰好叫 `-rf` 的也能被處理（`rm -- -rf`）。用現成的 argument parser 幾乎都免費支援。
- **`-` 代表 stdin/stdout**（見 `contract-io-and-exit.md`）。
- **用語言的標準 parser**（argparse/clap/cobra/commander…），別手刻 `argv` 迴圈——慣例（`--`、`-abc` 合併、`--flag=value`）人家都處理好了，手刻必漏。

## 子命令：何時需要

工具有**多個動詞**時用子命令（`git commit`、`docker run`），單一動詞別硬加：

- 判準：你的工具做「一件事」（grep 找、curl 抓）→ 不要子命令；做「一組相關操作」（版本控制、容器管理）→ 子命令。
- 子命令結構：`tool <noun-or-verb> [flags] [args]`，動詞命名一致（`add/remove/list/show`，別一處 `delete` 一處 `rm`）。
- 共通旗標（`--verbose`、`--config`）放全域，子命令專屬的放子命令層。
- **從單命令長成多命令很痛**（breaking change）——一開始就判斷會不會長出第二個動詞。

## 設定優先序：flag > env > 設定檔 > 預設

同一個選項可能來自四處，**優先序必須固定且符合直覺**（越接近本次呼叫、優先序越高）：

```
1. 命令列旗標      # 本次明確指定，最高
2. 環境變數        # 這個 session/CI 的設定
3. 設定檔          # 專案/使用者的持久偏好
4. 內建預設        # 最低
```

- 環境變數命名：`TOOLNAME_OPTION`（前綴避免撞名）。
- 設定檔位置遵守平台慣例（XDG `~/.config/`、專案根 `.toolrc`），並提供 `--config` 覆蓋。
- **別讓 env 蓋過明確旗標**——使用者打了 `--output json` 就是要 json，環境變數不該贏。

## 預設值：常見情況免旗標

**最常見的用法應該零旗標就對**——預設值做對，80% 的呼叫就是 `tool file`：

- 預設值選「最安全 + 最常用」的交集；危險的行為（覆寫、刪除）**永遠不做預設**（見 `ux-help-errors-and-tty.md` 的破壞性操作）。
- 若發現使用者每次都得帶同一組旗標，代表預設值選錯了。

## 常見坑

- **第 3+ 個位置參數**：順序沒人記得住——改旗標。
- **挪用 `-h`/`-v` 做別的**：打破肌肉記憶——標準旗標照慣例。
- **只有短旗標**：script 不可讀——短長成對，script 用長的。
- **手刻 argv 解析**：`--`、合併短旗標、`=` 語法必漏——用標準 parser。
- **單動詞工具硬上子命令**：`mytool run` 的 run 是廢話——一件事就一個命令。
- **env 蓋過明確旗標**：違反直覺——flag 最高。
- **危險行為當預設**：一跑就覆寫——破壞性永遠 opt-in。
- **介面隨意改**：別人的 script 就爆——介面是契約，改要走 deprecation。

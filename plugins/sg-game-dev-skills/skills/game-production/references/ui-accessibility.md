# 無障礙（Accessibility）

無障礙不是慈善加分題：字太小、色弱不可辨、不能重綁鍵，影響的是**一大票普通玩家**（大螢幕遠座距、8% 男性色弱、左撇子）。基本盤在設計期進成本極低，上線前補是重工。

## 基本盤清單（設計期就做）

**視覺**
- [ ] **字級可調**（至少 100% / 125% / 150%）：UI 佈局用自動排版（見 `ui-tech-specs.md`），字級縮放才不破版——這也是遠座距與掌機模式的剛需。
- [ ] **最小字級底線**：目標裝置實測（電視 3 公尺、手機臂長）可讀——同 `art-visual-readability.md` 的目標裝置原則。
- [ ] **色弱安全**：功能區分不只靠顏色（紅綠尤其），配形狀/圖示/明度雙編碼——visual-readability 的灰階測試直接複用；有餘裕再加色弱濾鏡選項。
- [ ] **對比度**：文字與背景的對比夠（動態背景上的 HUD 文字加半透明底或描邊）。
- [ ] **畫面閃爍節制**：全螢幕高頻閃爍（光敏性癲癇風險）避免或提供關閉——平台審核也會查（見 `build-release-checklist.md` 的合規）。

**操作**
- [ ] **按鍵重綁**：全部遊戲操作可重綁（UI 導航鍵可除外）——這同時服務左撇子、單手玩家、非標準鍵盤。
- [ ] **連打與長按替代**：連打 QTE 提供長按替代；長按確認提供切換式替代。
- [ ] **靈敏度與死區可調**：鏡頭靈敏度、搖桿死區開放設定（見 `../../game-design/references/feel-input-responsiveness.md` 的死區）。
- [ ] **震動可關**。

**聽覺**
- [ ] **字幕**：預設開啟、字級可調、有說話者標示；重要的 gameplay 聲音訊號（背後腳步、警報）考慮視覺化替代（方向指示器）——聲音是回饋系統（見 `audio-sfx-design.md`），聽不到的玩家需要等價回饋。
- [ ] **音量分軌**：音樂/音效/語音獨立滑桿（bus 結構的直接產出，見 mixing-and-loudness）。

**難度與時間**
- [ ] **難度選項誠實可用**：簡單模式不上鎖、不羞辱（成就不因難度剝奪要想清楚）。
- [ ] **暫停永遠可用**（單機）：包括過場——照顧的是「現實生活會打斷」的所有人。

## 設定選單的設計

- 無障礙選項集中一頁（玩家找得到），但同時散佈在相關分類（音量在音訊頁也有）。
- **首次啟動呈現關鍵選項**：字級與字幕在玩家看到任何小字之前先問。
- 所有選項即時預覽——調字級要當場看到效果，不是存了重開才生效。

## 驗收

- [ ] 灰階跑一輪主流程（色弱檢查）
- [ ] 最大字級全選單走一遍（破版檢查，同 `loc-layout-and-fonts.md` 的偽本地化思路——極端設定就是 UI 的偽本地化）
- [ ] 關掉聲音玩一場戰鬥（聽覺資訊的視覺替代檢查）
- [ ] 只用手把/只用鍵盤各通一次全選單（焦點導航完整性，見 `ui-interaction-feel.md`）

## 常見陷阱

- **當作上線前的 checklist**：字級可調要求自動排版、重綁鍵要求輸入抽象層——架構決定，事後補=重寫。與本地化同病（見 localization 的第一天原則）。
- **選項做了但預設爛**：字幕預設關、預設字級太小——大多數玩家不改設定，預設值就是大多數人的體驗。
- **色弱濾鏡當萬靈丹**：全螢幕濾鏡把美術也毀了——優先做「設計上不依賴單一顏色」，濾鏡是最後補強。
- **難度自尊設計**：把輔助選項藏很深或命名羞辱性（「嬰兒模式」）——選項的尊嚴影響它會不會被需要的人使用。

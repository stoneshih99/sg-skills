# 成長與經濟

core loop 的「進展」段（見 `gdd-core-loop-design.md`）拉長到整個遊戲，就是成長系統與經濟。企畫階段不用算出精確數值，但要把**結構**畫清楚：資源從哪來、到哪去、玩家憑什麼覺得自己一直在變強。

## 成長曲線

**玩家實力 = 角色數值 × 玩家技巧**。先決定你的遊戲兩者占比——這是類型定位問題，不是平衡問題：

- 數值主導（RPG、放置）：時間投入保證變強，爽點是「碾壓回去」。
- 技巧主導（動作、競技）：數值成長少，爽點是「我變厲害了」。
- 混合（多數遊戲）：數值成長給保底，技巧決定上限。

**曲線的形狀**（企畫層只需要決定形狀，數值後調）：

- **需求指數成長、供給線性成長**是多數遊戲的骨架：升級需求 ×1.5/級、產出 +10/級 → 自然形成前快後慢的節奏。
- **前期快**：前 30 分鐘要有 3-5 次「變強的可感時刻」（新技能、新裝備、數字跳一級），建立「投入→變強」的信任。
- **成長要可感**：+3% 攻擊力玩家無感；解鎖新動作、一刀清掉以前要三刀的怪才可感。**寧可少次而大顆，不要頻繁而無感。**
- **停滯點是設計出來的**：成長刻意放緩的位置，就是你希望玩家轉向的位置（挑戰技巧、探索支線、開新系統）——但停滯點若沒有替代活動，就是流失點。

## 資源迴圈：Source 與 Sink

把每種資源畫成「水池」：source（進水）→ 池子（存量）→ sink（出水）。

```
source（打怪掉落、任務獎勵、每日、產出建築）
   ↓
 池子（金幣存量）
   ↓
 sink（升級費用、消耗品、修理、手續費、賭抽）
```

企畫時列一張表，每種資源一行：

| 資源 | Source | Sink | 想製造的感受 |
|------|--------|------|-------------|
| <金幣> | <打怪、賣裝> | <升級、消耗品> | <日常小決策> |
| <稀有石> | <週限、成就> | <關鍵突破> | <攢很久花一次的儀式感> |

**結構規則：**

- **Sink 總量要能吃掉 source**，否則資源通膨：中後期金幣堆積如山 → 所有金幣獎勵失去意義 → 連鎖到所有用金幣當獎勵的內容報廢。通膨是經濟設計最常見的死法。
- **每種資源要有「玩家想要的 sink」**：稅與修理費是被動 sink（玩家討厭），想要的東西才是主動 sink（玩家心甘情願倒水）。
- **資源種類寧少勿多**：每加一種貨幣，就多一組 source/sink 要平衡。兩三種各司其職（日常決策 / 長期目標 / 特殊用途）通常夠了；五種以上多半是設計逃避——用新貨幣繞過舊經濟的問題。
- **兌換關係畫成圖**：資源之間能否互換（金幣買體力？）決定了經濟是一個池還是多個池。能互換的資源實質上是同一種，最強的 source 與最鬆的 sink 決定一切。

## 企畫層的檢查清單

- [ ] 說得出「數值 vs 技巧」的占比定位嗎？
- [ ] 前 30 分鐘有幾次可感的變強時刻？發生在哪？
- [ ] 每種資源的 source/sink 表列出來了嗎？有沒有只進不出的資源？
- [ ] 玩家長期最想要的東西，是不是一個主動 sink？
- [ ] 成長停滯點旁邊有沒有替代活動？
- [ ] 數值全部外化成表了嗎？（平衡是持續調整，寫死必死，見 `../../../architecture/game-architecture/references/data-config-driven.md`）

## 驗證方式

- **試算表先行**：正式做系統前，用試算表模擬「玩家每小時獲得/花費」推 10 小時、50 小時的存量曲線，通膨在表上就看得到。
- **玩測指標**：玩家在商店停留但不買（買不起還是不想要？）、資源存量只升不降、升級選擇永遠選同一個——都是經濟出問題的行為訊號（觀察法見 `playtest-hypothesis-and-metrics.md`）。

## 常見陷阱

- **獎勵貶值**：後期給前期資源（第 40 關還在掉金幣 ×100），獎勵感歸零。獎勵表要跟著進度換檔。
- **最優解單一化**：某個 source 效率碾壓其他玩法，玩家被迫刷同一件事——「最高效率的玩法」必須是「你希望玩家玩的玩法」。
- **用時間門檻假裝內容**：成長牆背後沒有新體驗，只有更大的數字，玩家爬過去發現「就這樣？」。
- **一次性 sink 用完就通膨**：所有 sink 都是「買斷式」（升滿就不再花），終局經濟必然失衡；要有循環 sink（消耗品、可重複的投入）。
- **企畫期跳過經濟**：「數值之後再說」的結果是系統做完才發現資源結構撐不起玩法，重工比先畫 source/sink 表貴一百倍。

# 節奏曲線（Pacing Curve）

好關卡的強度像心電圖，不是直線。「感覺平」的關卡幾乎都是節奏問題，不是內容量問題。

## 原則

- **緊張與釋放交替**：高強度段落後必須給釋放（安全區、獎勵、風景、輕鬆穿越）。沒有低谷，高峰就不成立。
- **整體向上，局部起伏**：關卡內的強度峰值逐段墊高，但每個峰之間要回落——鋸齒向上，不是斜線向上。
- **強度 ≠ 難度**：強度是玩家的喚起程度（緊張、專注、興奮），可以用敵人密度做，也可以用音效、視覺、時限、未知感做。Boss 前的安靜長廊強度很高，難度是零。

## 典型的關卡形狀

```
強度
 │            ▲ 高潮(Boss/大遭遇)
 │      ▲    ╱ ╲
 │  ▲  ╱ ╲  ╱   ╲
 │ ╱ ╲╱   ╲╱     ╲▁ 結尾釋放(獎勵/過場)
 │╱開場鉤子
 └──────────────────── 時間
```

- **開場鉤子**（前 30-60 秒）：一個小刺激讓玩家進入狀態——一場輕鬆勝利、一個景觀、一個懸念。不要用空走廊開場。
- **爬升段**：2-4 個強度漸增的遭遇，中間穿插釋放。
- **假結尾／反轉**（可選）：玩家以為結束時再給一波，適合中後期關卡。
- **高潮**：本關最高強度，用掉這關教的/考的所有東西。
- **釋放收尾**：獎勵、存檔點、安全的離場路徑。高潮後直接切下一關的高壓開場是常見錯誤。

## 難度爬升的做法

同一個機制，難度分層的常用軸（挑 1-2 個轉，不要全轉）：

1. **複雜度**：單一敵人 → 混編；單一機關 → 機關組合。
2. **精度**：容錯窗口變小（平台變窄、時機變嚴）。
3. **壓力**：加時限、加追擊、限制資源。
4. **遮蔽**：資訊變少（視野、提示、預告動作）。

## 檢查清單

- [ ] 畫得出這關的強度曲線嗎？（畫不出來 = 沒設計過節奏）
- [ ] 最高峰是否只有一個，且在後段？
- [ ] 每個高強度段之後有沒有釋放？
- [ ] 開場 60 秒內有沒有鉤子？
- [ ] 目標時長內，段落數是否合理（大約每 2-4 分鐘一個節奏轉折）？

## 常見陷阱

- **等距擺放**：敵人/機關均勻分佈，強度變直線，再多內容也平。
- **多峰同高**：三個「都很精彩」的大遭遇一樣強，玩家記不住任何一個。挑一個當高潮，其他降級。
- **只用戰鬥調強度**：穿越、解謎、敘事段落也是節奏工具；全戰鬥的關卡靠密度硬撐會麻痺。
- **高潮後不收尾**：Boss 倒地直接黑屏切關，情緒沒有著陸點，成就感打折。

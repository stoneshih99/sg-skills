# 打擊感回饋層

打擊感 = 同一瞬間疊加的多層小回饋。單看每層都微不足道，疊起來就是「爽」。原則：**每一層都短、都同步、都可關閉測試**。

## 回饋層清單（由必要到加分）

命中的一瞬間，依序檢查有沒有這些層：

- [ ] **音效**：命中音與揮空音分開；重擊音更低頻。音效是打擊感的一半，先做這個。
- [ ] **Hitstop（頓幀）**：命中瞬間雙方動畫凍結 2-6 幀（60fps 下約 30-100ms）。重攻擊更長，小攻擊可以零。這是「打到肉」的關鍵。
- [ ] **受擊閃白 / 變色**：被打的目標整體閃白 1-3 幀，立刻告訴玩家「有效」。
- [ ] **粒子 / 火花**：在命中點（不是角色中心）冒出，方向沿攻擊方向。
- [ ] **擊退（knockback）**：目標小幅位移或後仰，量級與攻擊強度成正比。
- [ ] **畫面震動（screen shake）**：小攻擊不震或極微震，重攻擊短促一震（0.1-0.2 秒內收斂）。方向性震動（沿攻擊方向）比隨機亂震高級。
- [ ] **受擊動畫**：目標有 hit reaction（後仰、踉蹌），哪怕只有 2-3 幀。
- [ ] **數字 / UI 回饋**：傷害數字彈出（若風格允許）、血條掉落有延遲殘影。
- [ ] **手把震動**：命中短震，與 screen shake 同步。

## 量級原則

- **短**：所有回饋在 0.2 秒內結束（hitstop 除外的視覺層）。回饋長了會拖節奏，連擊時互相堆疊成災難。
- **分級**：輕攻擊 / 重攻擊 / 終結技的回饋量級要拉開——全都最大聲等於沒有層次。建議做成資料表（見 `../../../architecture/game-architecture/references/data-config-driven.md`）統一調。
- **同步**：音效、hitstop、閃白、粒子必須同一幀觸發。差一兩幀就「散」。
- **收斂**：screen shake 用衰減曲線快速收斂，不要線性拖尾。

## 排查法

「打擊感很虛」時，逐層開關測試：

1. 全部關掉，只留動畫——確認基準。
2. 一次開一層，感受每層的貢獻。
3. 常見發現：音效太弱（換音效比調參數有效）、hitstop 根本沒做、粒子開在角色中心而非命中點。

## 常見陷阱

- **只靠 screen shake**：什麼都震，暈且廉價。震動是調味料不是主菜，hitstop + 音效才是。
- **回饋蓋過資訊**：粒子與閃光多到看不清敵人動作，打擊感不能犧牲可讀性。
- **連擊時回饋堆疊**：多段命中各觸發完整回饋，hitstop 疊加變慢動作、震動疊加成地震。多段命中要合併或衰減。
- **揮空無回饋**：揮空也要有風聲與動畫重量，否則攻擊「沒打到時像假的」。

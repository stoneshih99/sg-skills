# 遭遇設計（Encounter Design）

遭遇（encounter）是關卡的基本單位：一場戰鬥、一個解謎房、一段追逐。每個遭遇都該有一句話說得出的**意圖**——考什麼、或給什麼感覺。說不出意圖的遭遇就是填充物。

## 先寫意圖

- 「考驗玩家在移動中換彈的習慣」
- 「讓玩家第一次體會被包抄的恐慌」
- 「給一場輕鬆的屠殺，釋放上一段的壓力」

意圖決定一切後續選擇：敵人組合、空間、資源。反過來（先擺敵人再找理由）做不出有記憶點的遭遇。

## 敵人組合（以角色功能思考）

單一敵人是「音符」，遭遇是「和弦」。常見功能角色：

- **壓迫者（Pusher）**：近身逼玩家移動（衝鋒兵、近戰）。
- **控場者（Denier）**：封鎖區域逼玩家繞路（炮台、範圍攻擊、地雷）。
- **狙擊者（Sniper）**：懲罰站著不動的玩家。
- **肉盾（Tank）**：吸收火力、拖時間、擋路線。
- **增援者（Support）**：治療/強化他人，製造「先打誰」的決策。

**組合原則**：好的遭遇讓功能互相掩護——壓迫者把玩家從掩體逼出來，狙擊者懲罰暴露。玩家被迫在兩種威脅間做取捨，這就是深度。同功能疊加（五個衝鋒兵）只是數量，不是設計。

## 空間佈局

空間是遭遇的另一半，同一組敵人換個場地就是另一場戰鬥：

- **掩體節奏**：掩體間距決定移動的風險節拍。掩體太密 = 無壓力龜點；太疏 = 玩家不敢動。
- **高低差**：高位給資訊與射界優勢。把高位給玩家是賞賜，給敵人是壓力。
- **側翼路線**：至少一條繞行路線讓主動玩家有花招可玩；全正面的房間只能硬推。
- **進出口**：玩家從哪進（第一眼看到什麼 = 你的佈置舞台）、增援從哪來（要有預告：門、洞、音效）。
- **危險地形**：爆炸物、懸崖、陷阱給雙方利用，是玩家創意的出口。

## 資源擺放

- **戰前資源**是難度暗示：門口一堆彈藥 = 「裡面有大場面」，玩家會讀。
- **戰中資源**引導走位：把補給放在需要冒險的位置，逼玩家離開舒適點。
- **戰後資源**是節奏釋放的一部分（見 `level-pacing-curve.md`）。

## 變奏：同素材的多次使用

同一組敵人/機關，用變奏榨出多場不同的遭遇（也省製作成本）：

1. **換空間**：開闊場 → 窄走廊 → 有高低差的場地。
2. **換資源狀態**：充足彈藥 → 稀缺資源下重打類似遭遇。
3. **換組合**：舊敵人 + 一個新角色，整場決策就重新洗牌。
4. **換目標**：殲滅 → 防守 → 突圍 → 限時通過，同場地不同玩法。

## 檢查清單

- [ ] 這個遭遇的意圖一句話說得出來嗎？
- [ ] 敵人組合有沒有至少兩種互相掩護的功能？
- [ ] 玩家有沒有至少兩種可行打法？（只有一解的戰鬥是謎題，不是戰鬥）
- [ ] 站在玩家的進場點看：第一眼能不能讀出威脅與機會的大概分佈？
- [ ] 增援有沒有預告？（無預告的背後刷怪只會教玩家不信任關卡）

## 常見陷阱

- **用數量調難度**：加倍敵人數是最懶的難度調整，只增加時長與疲勞。改組合、改空間、改資源。
- **海綿化**：把血量拉高假裝有挑戰，玩家感受到的是拖延不是威脅。
- **一招鮮房間**：房間只允許一種解法，重玩價值歸零，玩家風格被否定。
- **忽略退出體驗**：戰鬥結束後的搜刮/離場動線沒設計，勝利的餘韻被找路消磨掉。

# 假設與判準

沒有假設的玩測會收到一堆意見，然後團隊挑自己想聽的。先寫假設與判準，測試才會產生「結論」而不是「感想」。

## 假設怎麼寫

格式：**「<誰> 能在 <條件> 下 <做到 / 感受到什麼>」**——可觀察、可證偽。

- 差：「看看新手教學行不行」（不可證偽）
- 好：「沒玩過本作的玩家，能在無口頭提示下於前 5 分鐘內學會二段跳並主動使用」

一場測試 **1-3 個假設**。超過三個，觀察會失焦，每個都測不深。

## 判準先寫死

測試前寫下「通過長什麼樣、失敗長什麼樣」，並存檔（見範本的判準表）。理由：人在看完測試後會自我說服——「他卡了十分鐘，但他最後說蠻好玩的」。判準先寫死就沒得凹。與 `gdd-risk-assessment.md` 的「判準先寫好」同一原則。

判準用**行為**描述，不用意見：

- 差：「玩家覺得教學清楚」
- 好：「5 人中 ≥4 人在第 3 關前主動使用二段跳（非誤觸）」

## 各階段該測什麼

| 階段 | 測什麼 | 不要測什麼 |
|------|--------|-----------|
| 紙上 / 灰盒原型 | 核心循環有沒有趣（樂趣風險） | 美術觀感、手感細節 |
| 垂直切片 | 體驗成不成立、教學能不能自學 | 內容量、平衡 |
| Alpha（系統齊） | 難度曲線、卡點、系統互動 | 錯字、音量 |
| Beta（內容齊） | 平衡、時長、留存鉤子、崩潰 | 核心玩法（現在改不動了） |

**階段錯配是最常見的浪費**：拿灰盒問美術意見、拿 beta 問「核心好不好玩」都得不到能行動的答案。

## 常用行為指標

- **上手時間**：第一次主動使用某機制的時間點。
- **卡點分佈**：每個卡住 > 60 秒的位置與脫困方式（自己想通 / 亂試 / 放棄）。
- **自然結束點**：允許自由離開時，玩家玩了多久、在哪裡停。這是最誠實的「好不好玩」指標。
- **重試意願**：失敗後按重來的速度（秒按 = 上鉤了；嘆氣放下手把 = 挫折超標）。
- **無提示完成率**：多少人不需協助通過教學段。

## 常見陷阱

- **測完才定判準**：等於沒有判準。
- **一場測太多**：假設超過三個，或一場同時測教學＋平衡＋手感，結果每項都只有印象沒有證據。
- **樣本錯誤**：用團隊成員或核心粉絲測「新手能不能學會」。受測者輪廓要貼假設。
- **把「不確定」硬判成通過**：3 人通過 2 人失敗就是不確定，結論是「再測」，不是「差不多啦」。
- **只測一輪**：改完不回測，永遠不知道改對還是改壞。小樣本多輪（3-5 人 × 多輪）勝過一次大樣本。

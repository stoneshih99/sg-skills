# 風格指南制定

風格指南的任務：把「我們要那種感覺」翻譯成**別人不用問你也能做對**的規範。形容詞不能執行，範例與規則才能。

## 從參照到規範

1. **收參照板（mood board）**：收 20-50 張「有那個感覺」的圖（遊戲截圖、插畫、照片、電影畫面），貼在一起看。
2. **萃取共同點**：這批圖共享什麼？飽和度高低？輪廓硬軟？光源戲劇性？材質乾淨或髒污？——寫下 5-8 條可觀察的特徵。
3. **做黃金樣本**：照這些特徵做出一份自己的資產（見 `content-pipeline-setup.md`）——參照板是別人的，樣本才是你的規格。
4. **寫成 do/dont**：每條特徵配一組對錯範例（外包規格包直接複用，見 `content-outsourcing-handoff.md`）。

> 檢驗標準：把指南交給沒參與討論的人做一件資產，不追問就能做到 80% 像——做不到就是指南還在寫形容詞。

## 色彩腳本（Color Script）

- **全遊戲的色彩規劃**：每個章節 / 區域一個主色調，排在一起看整體節奏（沼澤的綠灰 → 火山的紅黑 → 雪原的白藍）——色彩即進度感。
- **限縮調色盤**：定義主色 + 輔色 + 強調色（常見 3-5 色系），所有資產從盤內取色。盤外色是「特權」，保留給功能用途（見 `art-visual-readability.md` 的色彩功能分配）。
- **定義光照基調**：主光方向、冷暖對比、陰影顏色（純黑陰影 vs 帶色陰影差異巨大）——資產在統一光照下才可比。

## 輪廓與形狀語言（Shape Language）

- **形狀傳達個性**：圓 = 友善無害、方 = 穩重可靠、尖 = 危險敏捷。角色陣營 / 敵人類型可以用形狀家族區分——玩家不用看細節就能分類。
- **輪廓測試**：把資產填成純黑剪影還認得出是誰、在做什麼，輪廓才合格（角色尤其如此，見 `art-visual-readability.md`）。
- **細節密度分級**：主角細節最多、雜兵最少——細節密度就是視覺重要性的訊號。全員都精細 = 全員都不重要。

## 材質語彙

- 定義這個世界的材質規則：金屬多亮？布料多粗糙？邊緣磨損嗎？手繪紋理還是寫實掃描？——材質語彙不一致是「風格不統一」最常見的來源（模型都對、材質一亂就穿幫）。
- 做一張**材質球對照板**：常用材質（金屬/木/布/石/皮膚）各一顆標準球，新資產對著調。

## 指南的維護

- 指南跟黃金樣本一樣要版本化：風格演進是正常的，但要**顯式地改**（更新文件與樣本、舊資產排補課），不是默默飄移（見 `content-pipeline-setup.md` 的品質飄移）。
- 每批新資產抽查與參照板並排——偏了早發現早便宜。

## 常見陷阱

- **指南全是形容詞**：「有溫度的」「帶點黑暗但不壓抑」——每個人做出來都不一樣。特徵要可觀察、可對照。
- **參照板當風格**：直接照著參照畫 = 縫合怪 + 著作權風險。參照萃取特徵後就收起來，對照物換成自己的黃金樣本。
- **風格超出產能**：定了吃工時的風格（手繪逐幀、高寫實 PBR），量產期才發現單位成本撐不起內容量（見 `milestone-planning-and-estimation.md` 的切片實測）。風格決策 = 成本決策。
- **忽略「組起來」的樣子**：單件資產都漂亮，放進同一畫面互相打架——驗收永遠包含「進場景並排看」。
